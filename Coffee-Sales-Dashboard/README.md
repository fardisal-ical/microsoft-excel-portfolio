# Coffee Sales Dashboard

## Overview
Interactive sales dashboard built using a public coffee sales dataset. The project includes data cleaning, table merging, transformation, and dashboard creation in Microsoft Excel.

## Objectives
- Clean and transform raw sales data
- Merge multiple tables using Power Query
- Analyze sales performance
- Build an interactive dashboard

## Process
- Imported multiple datasets
- Cleaned and transformed data using Power Query
- Merged Orders, Customers, and Products tables
- Created calculated columns (Sales)
- Built Pivot Tables and Pivot Charts
- Designed an interactive dashboard with slicers

## Tools Used
- Microsoft Excel
- Power Query
- Pivot Tables
- Pivot Charts
- Data Visualization

## Dataset
Public Coffee Sales Dataset
